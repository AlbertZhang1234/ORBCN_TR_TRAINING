# SAP OData 连接流程

接入一个新的 SAP OData 服务时，按此流程执行。如果无法安全地确认连接信息，应停在实现之前，不要猜测。

## 1. 了解目标项目

确认运行时和部署边界、已有 HTTP 客户端、配置与密钥机制、代理/TLS 处理、错误模型、日志、依赖组装方式和测试工具。新增依赖前，先搜索现有的 SAP、OData、Destination、代理、OAuth、CSRF、Cookie Jar 和重试代码。

SAP 调用应位于可信的后端边界。对于以前端为主的应用，应提供应用自己的服务端 API，或使用平台提供的可信 SAP Destination/Connectivity 服务；禁止将 SAP 凭证写入前端代码。

## 2. 收集连接契约

获取或确认以下信息：

- SAP 基础 Origin，例如 `https://sap.example.com`；
- 准确的服务根路径，而不仅是某个实体 URL；
- OData V2 或 V4；
- 认证方式和身份模型；
- SAP Client、租户和语言要求，常见参数为 `sap-client` 和 `sap-language`；
- 代理、VPN、SAP Cloud Connector、DNS、防火墙白名单、mTLS 或自定义 CA 要求；
- 实体集、主键、读取、写入、Action/Function、批处理和预计数据量；
- 超时、限流和并发预期，以及是否存在安全的测试租户或测试实体。

常见的本地部署 V2 服务根路径类似 `/sap/opu/odata/sap/Z..._SRV`；V4 和 SAP 云产品可能使用完全不同的路径。以服务提供方给出的服务文档或元数据 URL 为准。

## 3. 在不修改数据的情况下验证连接

使用预定的认证方式和 SAP Client/租户请求 `<service-root>/$metadata`。优先发送 `Accept: application/xml`，因为元数据通常是 EDMX XML。请求服务根路径并读取 JSON 服务文档，也可以用来确认实体集。

编码前先对错误分类：

- DNS/TCP/TLS/代理失败：网络路径或证书信任配置问题；
- `401`：认证缺失、无效、过期，或此端点不接受该认证方式；
- `403`：身份缺少服务或 SAP 业务权限、Client 错误，或 Gateway 策略拦截；
- `404`：主机或路径错误、服务未激活、别名不匹配，或 Client 错误；
- `5xx`：SAP Gateway、后端或具体操作失败，应检查 SAP 关联信息和错误详情；
- `200` 但响应是 HTML：通常是登录页面、反向代理、SSO 重定向或端点错误，并不代表 OData 已连通。

不能把 HTML 登录页面视为连接成功。

## 4. 定义类型前先读取元数据

检查准确的命名空间、实体集和实体类型、复合主键及其顺序、`Edm.*` 属性类型、精度和小数位数、Nullable、最大长度、导航属性、Function Import/Action、Bound Operation，以及并发或 ETag 注解。确认服务是否严格区分字段大小写。

如果项目已经使用成熟 SDK 或生成工具，并且生成代码可维护，可以从元数据生成类型。否则，只定义应用实际使用字段的精简原始 SAP DTO。若只需要一个操作，不要复制整个元数据模型。

## 5. 实现最小读取

先对一个实体集执行带有上限的 `$top` 查询。需要时使用 `$select` 减少 Payload，并只增加固定且具有类型约束的 `$filter`。按服务真实的 V2 或 V4 结构解析响应，将数据项和服务端分页链接分别返回。

在集成边界把 SAP DTO 映射为应用或领域模型。转换规则明确前，保留 SAP 原始值，尤其是小数、日期、时区、布尔值、二进制字段和空值。

## 6. 谨慎增加写入

确认 HTTP 方法、实体或 Action 路径、Payload Content-Type、CSRF 策略、必要 Cookie、ETag 行为和 SAP 端验证规则。使用同一服务、会话和身份获取 CSRF Token 后再写入。对于 Deep Insert、Action、媒体或 `$batch`，必须遵循服务元数据和服务文档，不能假设它们等同于普通实体 POST。

预先定义请求发送后发生超时等不确定结果的处理方法。安全方案包括业务主键或幂等 Token、写后查询核对，或向用户明确展示“部分成功/结果未知”状态。未完成此决策前，禁止自动重试写入。

## 7. 验证和交付

为协议行为和数据映射增加模拟测试。增加只读的在线 `$metadata` 冒烟测试；没有配置时，应明确跳过或清楚说明失败原因。文档只列环境变量名称，不写真实值，并说明可信 CA/代理的配置和冒烟测试运行方法。

只有经过授权后才可执行在线写入测试。应使用指定的非生产租户和可唯一识别的测试记录，写入后读取核对结果；只有服务支持删除并且用户明确授权时，才清理测试记录。
